How the tests run

The suites have no dependencies (no JUnit), so they run anywhere a JDK is installed. Each exits with status 0 only if every check passes.

javac -d out src/assignment2/*.java tests/assignment2/*.java
java -cp out assignment2.AllTests          # both suites
java -cp out assignment2.WordleTests       # Wordle only
java -cp out assignment2.MastermindTests   # Mastermind: Phase I tests + Phase II regression

As in Phase I, tests work at three levels: pure scoring, the game API (with a FixedSecretSource, so the secret is known), and full console sessions fed through the same ConsoleRunner with an injected reader and writer. Phase II adds a fourth level: the real launcher, java assignment2.Driver …, run as a child process. The helpers (check, session, launch, allCodes) moved into a shared TestSupport class, so both suites use one harness.

Game-level Wordle tests use a 20-word list built in the test, so each expected value can be checked by hand. The "real word file" and launcher tests load the external data/words.txt exactly as the game does.

Required: repeated-letter cases

The assignment requires two kinds of repeated-letter test: (a) the guess has more copies of a letter than the secret, and (b) one occurrence is CORRECT while another occurrence of the same letter must not be marked PRESENT. All of these are checks in WordleTests.scoringRepeatedLetters().

Beyond the hand-picked cases, the rule is also tested as a property on 200,000 random pairs with heavy repetition: for every letter, #C + #P equals min(copies in secret, copies in guess). That is exactly "a secret letter can satisfy at most one guessed letter, and no possible match is missed".

Do the tests catch real bugs? Planted-bug check

To check that the tests are strong enough, one deliberate bug at a time was planted in a scratch copy of the code, and both suites were run against it. A good suite should fail on every planted bug.

M4 does not change Mastermind's black/white counts (only which repeated letter gets P), so only the Wordle tests can catch it, and they do.
